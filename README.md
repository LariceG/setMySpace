# setMySpace

Next.js project for the setMySpace birthday landing page and location selector.

## Requirements

```text
Node.js: v22.22.2
npm: 10.9.7
```

## Git Setup

Clone the project on another system:

```powershell
git clone https://github.com/LariceG/setMySpace.git
cd setMySpace
npm install
npm run dev
```

Open:

```text
http://localhost:3000/home
```

## Build

```powershell
npm run build
```

## Git Ignore

The project includes `.gitignore` so dependency, build, cache, and local environment files are not committed.
